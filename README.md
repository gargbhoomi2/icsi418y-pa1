## Application Name
Task Manager

## Description
Task Manager is a simple client-side web application that allows users to create and manage tasks. Users can enter a task name, choose a priority level, add the task, mark tasks as completed, and delete tasks.

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open the `index.html` file in a web browser.
4. Enter a task, select a priority, and click "Add Task".

## Known Problems / Incomplete Features
- Tasks are not saved after the page is refreshed.
- The application does not use a database or server.
